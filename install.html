Cài widget 汉字 📲

  1. Bấm nút vàng ở trên để copy script.
  2. Mở app Scriptable → bấm + → giữ tay vào ô trống → Paste.
  3. Bấm tên script ở trên cùng, đổi thành Mandarin, rồi bấm ▶️ một lần (cho phép thông báo).
  4. Giữ màn hình chính → + → Scriptable → thêm widget → giữ widget → Edit Widget → Script: Mandarin.
